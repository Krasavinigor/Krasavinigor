## Featured personal project

### [Raincoat — a weather-aware wardrobe app](https://github.com/Krasavinigor/Raincoat)

Upload clothing photos, review AI-suggested item details, and generate outfits for the next three hours of weather. I built it as a personal project to explore the full path from an interactive frontend to reliable GenAI jobs.

- **Frontend:** Next.js 16, React 19, TypeScript, SSR, TanStack Query, and English/Russian localization that preserves active work when switching languages.
- **AI integration:** OpenAI vision and Structured Outputs, followed by domain validation against real wardrobe items and weather rules.
- **Reliability:** a PostgreSQL-backed worker, SSE job-status updates, idempotency, and cost controls. A local sample demo runs without a database or API key.

The [repository](https://github.com/Krasavinigor/Raincoat) includes the architecture, setup instructions, and verification results.
